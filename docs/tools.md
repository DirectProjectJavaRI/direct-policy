# Tools

This section describes how to author a policy definition. It includes an in-depth description of the Simple Text V1 lexicon and the tools for creating and testing policy definitions.

* [Simple Text Lexicon](stext-lexicon) — Full syntax rules and a complete description of the Simple Text lexicon.
* [Policy Builder](pol-builder) — A text-editor-based tool for writing and testing policies expressed in the Simple Text lexicon.
* [Examples](examples) — Example policies for common use cases.
